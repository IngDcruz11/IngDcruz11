Soy **David Cruz**, estudiante de **Ingeniería en Sistemas y Ciencias de la Computación** en la Universidad Mariano Gálvez de Guatemala 🇬🇹.

Me apasiona el desarrollo de software y la creación de soluciones tecnológicas que resuelvan problemas reales. Tengo especial interés en la arquitectura backend, las aplicaciones web, las bases de datos y la automatización de procesos.

## 🚀 Proyectos destacados

### 🎓 AulaNova ERP — Sistema de gestión académica

Sistema de administración académica desarrollado con una arquitectura moderna, orientado a optimizar procesos institucionales.

**Tecnologías:** NestJS, TypeScript, PostgreSQL, Supabase y React.

**Características principales:**
- Gestión de estudiantes, docentes, cursos e inscripciones.
- Control académico, asistencias y calificaciones.
- Administración de usuarios, roles y permisos.
- Generación de reportes y documentos.
- Integraciones con servicios externos y funcionalidades de IA.

### 🏥 Sistema de gestión médica

Aplicación web para administrar operaciones de un centro médico.

**Tecnologías:** Laravel, Vue.js y MongoDB.

**Características principales:**
- Administración de pacientes y colaboradores.
- Gestión de citas, habitaciones y horarios.
- Control de facturación y servicios.
- API REST e interfaz web responsiva.

### 📄 Sistema de solvencias estudiantiles

Aplicación para consultar, generar e imprimir constancias de solvencia de pagos estudiantiles.

**Tecnologías:** React, Node.js, Express y Google Apps Script.

**Características principales:**
- Consulta de información desde Google Sheets.
- Validación del estado de pagos.
- Generación de constancias listas para imprimir.
- Interfaz adaptable a dispositivos móviles.

🔗 [Ver repositorio](https://github.com/IngDcruz11/academia-fs-solvencias)

### 🌱 Automatización e IoT

Prototipos de automatización utilizando microcontroladores ESP8266 y sensores electrónicos.

**Tecnologías:** C++, Arduino IDE, ESP8266, sensores y actuadores.

**Áreas de aplicación:**
- Sistemas de riego automatizado.
- Monitoreo de condiciones ambientales.
- Control de servomotores y dispositivos.
- Interfaces web para supervisión y control.
